    Architecture decisions¶

    The decision log holds every architecture decision of GBO in MADR format. It contains the decisions of the archived reference architecture v0.6.2. It also contains the decisions that the GBO team made during the build of the demo.

    Each ADR names the PSA or GO constraint that it satisfies and the deliberation that produced it. Each ADR also links to its implementation in gbo-demo at release v0.9.0. A "Traceability" section at the end of each ADR lists the requirements, findings, open questions, and demo increments that the ADR depends on.

    If a later decision replaces an earlier one, both stay in the log. At the top of its body, the superseded ADR gives the reason. It keeps its text as history.

    The column "Serves" names the main requirements of each decision. The full list is in the ADR.
